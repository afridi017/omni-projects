# AfridiVerse OS

The Omni Command Center for IB Afridi's CODEX project universe.

## Included

- Kali-style boot sequence
- 13 project app icons
- Draggable, resizable, minimizable project windows
- Project previews and live/local launch links
- Fake terminal commands: `whoami`, `ls ~/empire`, `cat motto.txt`, `launch huntverse`, `launch noor`
- Cmd/Ctrl+K Spotlight project launcher
- PKT/EAT live clock
- Three.js starfield and globe
- Wallpaper switcher with localStorage persistence
- PWA manifest for GitHub Pages / installable shell
- Responsive mobile app drawer layout

## Run

Open `index.html` directly or serve the folder with:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500/`.

This is a frontend OS prototype. Project preview windows use local or public links where available; it does not replace the individual project runtimes.
