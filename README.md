## 🚀 Quick Start

The visual projects are dependency-light and can be opened directly:

```powershell
Start-Process .\ib-afridi-huntverse\index.html
Start-Process .\khyberverse\index.html
Start-Process .\sehatverse-qanoonverse\index.html
Start-Process '.\school managment system\index.html'
Start-Process .\ib-afridi-portfolio\index.html
Start-Process .\noors-blush-garden\index.html
```

For a local static server:

```bash
python -m http.server 5500
```

Then open a project under `http://localhost:5500/`.

## 🛡️ Responsible Security Use

The security tools and HuntVerse concepts are for **authorized testing, education, and legal lab environments only**.

- Define written scope before testing.
- Never scan or exploit systems without explicit permission.
- Keep proof-of-concept work minimal and non-destructive.
- Do not commit secrets, tokens, private reports, or production data.
- Report findings responsibly through the asset owner's disclosure process.

Frontend recon interfaces in this archive are visual prototypes and do not perform live scanning.
